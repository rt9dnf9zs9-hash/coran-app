# Texte coranique (Tanzil)

Déposez ici les fichiers téléchargés sur https://tanzil.net/download :

- `quran-simple.txt` — Quran type : **Simple**, output : **Text (with aya numbers)**
- `quran-uthmani.txt` — Quran type : **Uthmani**, output : **Text (with aya numbers)** (recommandé)

Puis lancez `pnpm import:quran`, qui génère `supabase/quran.sql` (à exécuter dans l'éditeur SQL de Supabase).
